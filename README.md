## Projetos em destaque

<a href="https://github.com/matheusprtlh/JarvisM"><img src="assets/project-1.svg" alt="Card do projeto JarvisM" width="100%" /></a>

### [JarvisM — Assistente de voz com IA](https://github.com/matheusprtlh/JarvisM)

Assistente de voz pessoal para Windows, criado como projeto independente. Combina ativação por palavra-chave, transcrição local de fala, respostas geradas por IA, síntese de voz, histórico de conversas e ações no computador, como abrir aplicativos e controlar o volume.

**Tecnologias:** Python · Whisper · Gemini API · Edge TTS · WebView2

### Plugin-Octoprint — Integração de sistemas

Projeto freelancer de integração do **ecossistema Bambu Lab** com um sistema web especializado da área médica. Desenvolvido para atender a um fluxo específico de um cliente, com foco na comunicação entre sistemas.

**Situação:** implementação específica para cliente. O repositório permanece privado; sua divulgação pública ainda depende de revisão.

<a href="https://github.com/matheusprtlh/EditallQ"><img src="assets/project-3.svg" alt="Card do projeto EditallQ" width="100%" /></a>

### [EditallQ — Monitoramento de licitações com IA](https://github.com/matheusprtlh/EditallQ)

**Protótipo de automação em n8n** que consulta dados de contratações públicas do PNCP e utiliza IA para avaliar a relevância de oportunidades. Extrai informações de editais e prevê persistência de dados, prevenção de duplicidades e notificações via WhatsApp.

**Tecnologias:** n8n · API REST do PNCP · Claude AI · JavaScript · PostgreSQL · Evolution API  
**Situação:** em desenvolvimento; algumas integrações ainda precisam de configuração e testes completos.
